# Event hub

Event Hub — это платформа для поиска и просмотра событий с современным UI и удобной системой фильтрации. Пользователь может просматривать список ивентов, искать мероприятия по категориям, дате, посещаемости и другим параметрам, открывать подробную страницу события и сохранять интересующие события..

---

## Функционал
загрузка и отображение событий из базы данных;
фильтрация и сортировка ивентов;
поиск по событиям;
пагинация / подгрузка данных частями;
регистрация и авторизация пользователей;
система избранного;
адаптивный premium-style интерфейс;
backend на Supabase;
готовая основа для будущего мониторинга и автоматического парсинга новых событий.

Установка и запуск

1. Скачать проект
2. Открыть папку проекта
3. Запустить:

```bash
npm install
npm run dev
---
```
Добавление Евентов
1. Получить евенты от ticketmaster API
2. Вставить результат в SupaBase
```bash
npm run import:ticketmaster -- --size=10
npm run import:ticketmaster -- --size=10 --commit
---
```
