## Команда проекта

* **Разработчик (Lead Developer):** Ярослав — реализация логики и кода
* Обязанности: пишет основной код проекта, настраивает структуру проекта, соедяет фронтенд и логику, решает технические проблемы. 
* **UI/UX Дизайнер:** СОфия — разработка интерфейса
* Обязанности:придумывает внешний вид интерфейса, делает макеты экранов, выбирает цвета, шрифты, расположение элементов, рисует прототип.
* **QA Tester:** Егор — тестирование и поиск ошибок
* Обязанности:проверяет проект на ошибки, тестирует разные сценарии, пишет список багов, предлагает улучшения.
* **Project Manager:** Саша — документация и презентация
* Обязанности:пишет описание проекта, делает презентацию, готовит объяснение как работает проект.
